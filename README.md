# Logiciel de facturation – Cabinet PsyH

Application web de facturation électronique destinée au cabinet **PsyH – Céline Bourbon, Psychologue**.

## Fonctionnalités
- Création, édition, liste des clients (adulte / étudiant)
- Création de factures avec colonnes : Service | Qté-heures | Prix | Total
- Référence automatique au format `JJMMAAAA` + lettre majuscule aléatoire
- Tarifs automatiques selon le type de client (70€ ou 50€ pour 55 min)
- Génération de factures PDF imprimables incluant toutes les mentions légales
- Statut de facture (Payée, En attente, Annulée)
- Interface web simple
